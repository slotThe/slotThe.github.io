Here is a list of hard and software, but most of this should not really surprise anyone.

# Hardware

+ Laptop: [TUXEDO Aura 14](https://www.tuxedocomputers.com/en/TUXEDO-Aura-14-Gen3.tuxedo)

  It's *fine*, but I kinda wish I'd gone for a [Framework](https://frame.work/) instead.
  Battery life after two years is already down by around 50%.
  Supported a local-ish company, I guess, which is something.

+ Keyboard: [Keyboardio Atreus](https://shop.keyboard.io/products/keyboardio-atreus)

  This keyboard is so good—and small enough that I can just carry it between my home and my work,
  meaning I can just have one and be happy.
  I've written a [review](/posts/atreus-review.html) about it at some point,[^2]
  in case you want to have a look.

+ Phone[^1]: [Fairphone 3](https://support.fairphone.com/hc/en-us/articles/4402587214737-Fairphone-3-End-of-Sales)

# Software

Most of these programs are heavily configured.
My dotfiles are [freely available](https://codeberg.org/slotThe/dotfiles) on Codeberg.

+ OS: [NixOS](https://nixos.org/)
+ Window manager: [XMonad](https://xmonad.org/)
+ Terminal emulator: [ghostty](https://ghostty.org/)
+ Shell: [fish](https://fishshell.com/)

  Fish is such a joy to use.
  Since I already spend way too much time customising Emacs,
  I figured that having a shell that "just works" might be a good choice—and it was!

  Special shout out goes to eshell, which I also sometimes use in case extra Emacs integration is necessary.
+ Coding: [Emacs](https://www.gnu.org/software/emacs/) ([Emacs])
+ Mail: [notmuch](https://notmuchmail.org/) ([Emacs])
+ Notes: [Org-roam](https://www.orgroam.com/) ([Emacs])
+ To-Do: [Org](https://orgmode.org/) ([Emacs])
+ Calendar: [Org](https://orgmode.org/) ([Emacs])
+ RSS Reader: [elfeed](https://github.com/emacs-elfeed/elfeed) ([Emacs])
+ Browser: [Firefox](https://www.firefox.com/de/)
+ Chat: [Matrix](https://matrix.org/), [Signal](https://signal.org/), [Telegram](https://telegram.org/)
+ Password Manager: [pass(1)](https://www.passwordstore.org/)
  * 2FA: [pass-otp](https://github.com/pass-extension/pass-otp)
+ VPN: [Mullvad](https://mullvad.net/)
+ Static site generator: [Hakyll](https://jaspervdj.be/hakyll/)
+ Hosting: [Microsoft GitHub Pages](https://docs.github.com/en/pages)
+ LaTeX: [AUCTeX](https://www.gnu.org/software/auctex/index.html) ([Emacs])

[^1]: Eww, I know. But try surviving in today's world without occasionally having access to a phone...

[Emacs]: https://www.gnu.org/software/emacs/

[^2]: Though the "review" mostly ended up as me being happy that [QMK](https://qmk.fm/) exists.
