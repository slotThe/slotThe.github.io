Uses This

Here is a list of hard and software, but most of this should not really surprise anyone.

Hardware§

  • Laptop: tuxedo Aura 14

    It’s fine, but I kinda wish I’d gone for a Framework instead. Battery life after two years is already down by around 50%. Supported a local-ish company, I guess, which is something.

  • Keyboard: Keyboardio Atreus

    This keyboard is so good—and small enough that I can just carry it between my home and my work, meaning I can just have one and be happy. I’ve written a review about it at some point,
    Though the “review” mostly ended up as me being happy that qmk exists.
    in case you want to have a look.

  • Phone
    Eww, I know. But try surviving in today’s world without occasionally having access to a phone…
    : Fairphone 3

Software§

Most of these programs are heavily configured. My dotfiles are freely available on Codeberg.

  • OS: NixOS

  • Window manager: xmonad

  • Terminal emulator: ghostty

  • Shell: fish

    Fish is such a joy to use. Since I already spend way too much time customising Emacs, I figured that having a shell that “just works” might be a good choice—and it was!

    Special shout out goes to eshell, which I also sometimes use in case extra Emacs integration is necessary.

  • LaTeX: AUCTeX (Emacs)

  • Mail: notmuch (Emacs)

  • Notes: Org-roam (Emacs)

  • To-Do: Org (Emacs)

  • Calendar: Org (Emacs)

  • RSS Reader: elfeed (Emacs)

  • Coding: Emacs (Emacs)

  • Browser: Firefox

  • Chat: Matrix, Signal, Telegram

  • Password Manager: pass(1)
    • 2FA: pass-otp

  • VPN: Mullvad

  • Static site generator: Hakyll

  • Hosting: Microsoft GitHub Pages
